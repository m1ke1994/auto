# Local block editing MVP

Existing complete Cinematic projects with a saved tracknode-agent-site.zip can edit the seven semantic roots (home, header, about, services, benefits, contacts, footer). An archive with a missing or ambiguous root fails before the paid request. Quick projects remain unchanged. The editor sends one bounded DeepSeek JSON request with the target markup, its component context and CSS. No automatic retries, asset search or Visual Critic call. This is not a full agent run; costs depend on tokens. The patch preserves the outer tag, component script and all bytes outside the selected root, appends root-prefixed CSS rules, and optionally upgrades the two trusted motion runtime files for Hero. It cannot change data declared in shared scripts, add new components or replace images/models via download. Existing local media remain available. Full source is rebuilt and audited with the existing isolated pipeline; the accepted project and ZIP are not overwritten. Visual quality is explicitly unverified. Scoped markup/CSS is not a proof of pixel-identical rendering elsewhere: shared styles, scroll timelines and section sizes can affect the result. Inspect the before/after preview. Accept switches the project's run directory; rollback switches to the saved base. Previous outputs remain on disk. A failure leaves the original intact.

Local update: rebuild openhands, builder and audit images, then start-studio.ps1 -RestartWatcher -Test while the queue is idle. Docker agent build runs offline block patch unit tests. Django tests cover queue/owner isolation/accept/rollback using fake output directories. Live Windows/Chromium E2E and real model API response require a local test; no new paid request is needed for unit tests.
