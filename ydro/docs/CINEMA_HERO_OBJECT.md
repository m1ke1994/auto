# Cinema hero object contract
New cinema runs with a matching supported subject and no imported model now select a trusted subject-matched procedural object (serum, jar, tube, perfume, cup, vase, watch, ring, microphone). Explicit photo-only and no-3D instructions opt out. Other industries retain the existing composition choices and must plan a subject-specific focal point; they do not receive cosmetic objects. The component is exported, reserved against agent overwrites, and its literal use in home is checked before source export. The stage uses local geometry, event-driven scroll rendering, capped DPR/resolution, mobile/reduced-motion static fallback, and no external model downloads. The object stage uses a local RoomEnvironment/PMREM reflection probe, physically based glass transmission, ceramic/plastic clearcoat, metallic hardware, curved labels, a folded satin environment and a scroll-driven camera/light choreography. It remains original procedural illustration, not a claim of photorealistic product photography. The source gate is heuristic, not a visual approval. Existing sites and checkpoint archives remain compatible. Docker unit tests cover selection, opt-out, reserved source, and the source contract. Full browser/render quality must be verified separately. No extra AI request is introduced by preset selection.

A new browser audit verifies procedural stage size, separation from copy, rendered fallback, and on desktop two distinct scroll-linked WebGL poses. A failed desktop motion check is deliberately not auto-repairable (it could be a WebGL infrastructure failure). Structural review fallback is explicitly labeled automated, does not claim AI review, and never bypasses any source validation. It allows new otherwise complete runs to reach local build/audit without an additional paid request.


## Subject-matched object families
The art director selects only a supported focal object that is semantically relevant to the brief: beauty products (serum/jar/tube/perfume), coffee (cup), floristry/decor (vase), jewelry (ring), watchmaking (watch), and podcast/music studios (microphone). Cars, architecture and unmatched subjects retain a model/photo/SVG direction rather than receiving a mismatched cosmetic prop. Explicit no-3D/photo-only requests remain authoritative. The offline browser smoke suite covers all nine presets on desktop and mobile (18 cases), including scroll pixel change, mobile static fallback, no horizontal overflow, and offscreen stability.
