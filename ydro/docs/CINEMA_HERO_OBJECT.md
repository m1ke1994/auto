# Cinema hero object contract
New cinema runs with a matching beauty/product subject and no imported model now select a trusted procedural object (serum, jar, tube, perfume). Explicit photo-only and no-3D instructions opt out. Other industries retain the existing composition choices and must plan a subject-specific focal point; they do not receive cosmetic objects. The component is exported, reserved against agent overwrites, and its literal use in home is checked before source export. The stage uses local geometry, event-driven scroll rendering, capped DPR/resolution, mobile/reduced-motion static fallback, and no external model downloads. This is illustrative geometry, not photorealistic glass. The source gate is heuristic, not a visual approval. Existing sites and checkpoint archives remain compatible. Docker unit tests cover selection, opt-out, reserved source, and the source contract. Full browser/render quality must be verified separately. No extra AI request is introduced by preset selection.

A new browser audit verifies procedural stage size, separation from copy, rendered fallback, and on desktop two distinct scroll-linked WebGL poses. A failed desktop motion check is deliberately not auto-repairable (it could be a WebGL infrastructure failure). Structural review fallback is explicitly labeled automated, does not claim AI review, and never bypasses any source validation. It allows new otherwise complete runs to reach local build/audit without an additional paid request.
