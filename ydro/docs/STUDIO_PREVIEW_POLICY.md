# Studio local preview policy

A successful Vite build and complete passing desktop/mobile Chromium audit are still mandatory. The Studio watcher runs studio-quality.ps1 with -AllowVisualWarnings and zero paid repairs. A visual score under 85, critic rejection (including critical findings), unavailable critic or skipped critic does not discard a technically valid local draft. No draft is called premium or published automatically. The strict CLI default remains unchanged. The generated run contains studio-result.json with status, score (if available), threshold 85 and technical_passed. The API and Studio distinguish visual acceptance from technical preview; legacy/imported runs without a trusted pipeline marker are unverified. Source download is unavailable if the source ZIP is missing.

An optional Sketchfab asset whose catalog or rendered-image critic returns invalid data/unavailable falls back to photography rather than accepting an unreviewed model. Required models still fail closed. The 75/85 candidate thresholds are unchanged. The main OpenHands budget remains an estimate of $2.50, excluding separate preflight/critic requests.

Update locally while the queue is idle: .\\start-studio.ps1 -RestartWatcher -Test. Run .\\studio-visual-policy.ps1 -SelfTest and rebuild the agent for its offline unit tests. No new paid request is needed for these tests. Existing completed projects remain accessible. Existing failed runs are not automatically promoted; import an already technically audited run with import_studio_run if desired (visual status remains unverified).
